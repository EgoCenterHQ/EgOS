# qbt-sort.py

| | |
|---|---|
| **Path** | `extras/qbtt/scripts/qbt-sort.py` → in the container `/scripts/qbt-sort.py` (read-only) |
| **Generated by** | section 11a of the EgOS4 scripts |
| **Started by** | qBittorrent, "Run external program on torrent finished": `python3 /scripts/qbt-sort.py "%K"` |
| **Log** | `/config/qbt-sort.log` (on the host: `qbittorrent/config/qbt-sort.log`) |
| **Trial run** | `docker exec qbittorrent-nox python3 /scripts/qbt-sort.py <hash> --dry-run` |

## Purpose

Sorts completed torrents into `/Films`, `/SerieTv` or `/Musics/<Artist>/<Album>/` (the layout Jellyfin expects).
It uses the Web API (`torrents/setLocation`), so qBittorrent itself moves the files and seeding continues from the new
location. It never makes qBittorrent fail: every exception is logged and the script exits with 1.

## Constants

| Name | Contents |
|---|---|
| `LOG`, `CONF` | log file and `qBittorrent.conf` |
| `API` | `http://127.0.0.1:<port>/api/v2/` (no login needed: "Bypass authentication for clients on localhost") |
| `DEST` | `video_movie → /Films`, `video_series → /SerieTv`, `audio → /Musics` |
| `EXT_VIDEO`, `EXT_AUDIO` | recognised extensions |
| `EXT_RISKY` | executables and scripts (`exe, msi, bat, ps1, sh, jar, apk, dmg, deb, …`) |
| `WARNING_FILE` | `POTENTIALLY HARMFUL` (Italian `POTENZIALMENTE DANNOSO` before 4.2.3) |
| `RE_SERIES` | `S01E02`, `S01`, `1x02`, `Season 1`/`Stagione 2`, `Complete Series`, `Ep 01` (season/stagione only when followed by a number: "The Four Seasons" is a film) |
| `RE_YEAR`, `RE_TAG` | title + year (takes the last one: "Blade.Runner.2049.2017"); cut at quality tags (`1080p`, `bluray`, `x265`, `ita`, …) |
| `RE_FEAT`, `RE_ARTIST_ALBUM` | removal of "feat./ft./featuring"; "Artist - Album" pattern |
| `UNKNOWN_ARTIST`, `VARIOUS_ARTISTS` | fallback values |

## Functions

| Function | Description |
|---|---|
| `webui_port()` | Web UI port: from `QBT_WEBUI_PORT` or, since the image's `doas` clears the environment, from `WebUI\Port=` in `qBittorrent.conf`; default `8082` |
| `movie_folder(name)` | `'BlacKkKlansman.2018.1080p.BluRay'` → `'BlacKkKlansman (2018)'`: strips the video extension, extracts title and year (or cuts at the first tag), dots/underscores → spaces, removes invalid characters |
| `clean_name(name)` | makes a tag usable as a folder name (`AC/DC` → `AC-DC`), max 150 characters |
| `main_artist(artist)` | strips the "feat. …" part |
| `names_from_title(name)` | fallback: `(artist, album)` from "Artist - Album (Year) [FLAC]" |
| `music_names(t, files)` | `(artist, album)` for an audio torrent: majority of the track tags (albumartist > artist; with ≥ 3 artists and no majority = "Various Artists"; album if ≥ 80 % agree), then the torrent name, then "Unknown Artist"/"Unknown Album" |
| `free_name(parent, name, own)` | `name`, or `name (2)`, `name (3)`… if it already exists and is not the torrent's current location (existing albums are never merged) |
| `risky_files(files)` | list of files with a risky extension (also `song.mp3.exe`) |
| `mark_risky(name, risky, folder, dry)` | writes a `WARN` line to the log and, if the torrent has its own folder, creates the `POTENTIALLY HARMFUL` file there with the list |
| `log(msg)` | timestamped line on stdout and in the log file |
| `api(path, data)` | GET/POST to the local Web API |
| `torrent_info(hash_)` | torrent data (`torrents/info`) or `None` |
| `wait_for_move(hash_, max_seconds=3600)` | waits until the state is no longer `moving` (e.g. from the temporary folder) |
| `root_folder(files)` | name of the root folder if all files are in a single one |
| `classify(name, files)` | `audio` if the audio files weigh more; `video_series` if the name or ≥ 2 videos look like episodes; otherwise `video_movie`; `None` if there is neither audio nor video |
| `main()` | see below |

## Flow of `main()`

1. Arguments: `<hash>` and optional `--dry-run`.
2. `wait_for_move`; if the torrent does not exist → `ERROR`.
3. Reads the files (`torrents/files`).
4. **Risky files** → `mark_risky`, log `HOLD`, the torrent stays in `/downloads`.
5. `classify`; no audio/video → `SKIP`.
6. Works out destination and renaming:
   - single-file film → folder `Title (Year)`;
   - film already in a folder → renames the folder to `Title (Year)`;
   - audio → `/Musics/<Artist>/<Album>` (artist folder created if missing, album with `free_name`).
7. Already in the right place → `SKIP`; destination not mounted → `ERROR`.
8. `--dry-run` → log `DRY` and stop.
9. `torrents/renameFolder` if needed, `torrents/setLocation`, waits for the move to finish; if the location has not
   changed (e.g. permissions) → `ERROR`, otherwise `MOVE`.

Log prefixes: `MOVE`, `SKIP`, `HOLD`, `WARN`, `MKDIR`, `DRY`, `ERROR`.
