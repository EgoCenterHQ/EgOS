# Cockpit page "Storage pool"

| | |
|---|---|
| **Path** | `/usr/share/cockpit/egos-storage/` (`manifest.json`, `index.html`, `egos-storage.js`, `egos-storage.css`) |
| **Generated by** | section 11b of the EgOS4 scripts |
| **Technology** | plain HTML/JS + `../base1/cockpit.js` (Cockpit 337 ships no PatternFly in base1) |
| **Access** | `https://egocenter.local:9090` → menu **Storage pool** (position 35; keywords egos, pool, disk, mergerfs, storage, samba) |

## Principle

The page is only a front end for [`egos-storage`](egos-storage.md): it reads the state with
`egos-storage status --json` and `disks --json` and starts every change as `egos-storage job …` (a systemd unit).
Closing the page **never interrupts** a format or a copy. All safety checks stay in
`egos-storage`. Cockpit administrative access is required (`superuser: "require"`).

| **Last operation** card | job status and log |
| `<dialog id="dlg">` | confirmation dialog reused by every action |

## JavaScript functions (`egos-storage.js`)

Constants: `TOOL = /usr/local/sbin/egos-storage`, `POLL_IDLE = 10000` ms, `POLL_JOB = 2000` ms.
State: `state` (last JSON), `timer`, `lastJobRunning`. `$` = `document.getElementById`.

### Utilities

| Function | Description |
|---|---|
| `run(args)` | `cockpit.spawn([TOOL, …args], {superuser: "require"})`: runs egos-storage as root |
| `fmtBytes(n)` | formats bytes as B/KB/MB/GB/TB/PB (base 1000); `-` if absent |
| `el(tag, cls, text)` | creates a DOM element with class and text (always `textContent`, never HTML) |
| `badge(text, kind)` | creates a `<span class="badge kind">` |
| `setBadge(node, text, kind)` | updates an existing badge |
| `applyTheme(style)` | follows Cockpit's light/dark theme (`localStorage["shell:style"]`, `cockpit-style` event, `prefers-color-scheme`) by adding/removing the `dark` class |

### Rendering

| Function | Description |
|---|---|
| `renderPool(st)` | pool badge (`not mounted` / `degraded` / `system disk only` / `ok`); usage bar computed **on the data disks only** when there are any (red ≥ 90 %); system-disk row (`new files` if RW, `old files only` if NC); one row per branch with status (`new files`, `not in pool`, `NOT MOUNTED`, "stray" files on the system disk) and a Remove button; `banner-health` if a branch is missing or not in the pool, or if the pool is not mounted |
| `renderStack(st)` | key/value list of the stack paths with badge `pool` / `system disk` / `pool NOT MOUNTED` |
| `renderDisks(all)` | table of the disks that can be added (excluding those already mounted under `/srv/egos/disks/`); if a disk has mounted partitions it shows "in use: unmount it first" instead of the button |
| `renderJob(st, log)` | job badge (`running`, `finished`, `failed (rc)`, `idle`) read from the `== END rc=` marker; cleans the `\r` of rsync/dd progress bars; disables the buttons during a job; shows **Move data to pool** only if the stack is not on the pool; enables **Empty system disk** only if there is a disk in the pool and files are left on the system disk; enables **Retry missing disks** only if there is a problem; shows `banner-held` |

### Loop and actions

| Function | Description |
|---|---|
| `refresh()` | reads `status --json`, `disks --json` and the last 40,000 characters of the log; on access denied shows `banner-admin`, otherwise `banner-error`; then calls the renderers and reschedules itself every 2 s during a job, every 10 s when idle |
| `startJob(args)` | `egos-storage job …args`; on error shows the banner; scrolls to the log and refreshes |
| `dialog({title, body, okText, okKind, confirmWord, checkLabel})` | opens the modal and returns a Promise with `{checked, typed}` or `null`. If `confirmWord` is set the OK button stays disabled until exactly that word is typed |
| `askAdd(d)` | confirms "Erase and add" by typing the device name → `job add --disk D --confirm D` |
| `askRemove(b)` | warns (last disk, files no longer available), confirms by typing `dataN` → `job remove --branch dataN --confirm dataN` |
| `askLink()` | explains the copy and offers the "Also move the Immich photo originals" checkbox → `job link --yes [--immich]` |
| `askReattach()` | → `job reattach` |
| `askDrain()` | → `job drain` |
| `DOMContentLoaded` | applies the theme, wires the buttons, first `refresh()`, shows the body when the Cockpit transport is ready |

## CSS (`egos-storage.css`)

Styling in line with Cockpit (cards, `ok`/`danger`/`busy` badges, `warn`/`danger` banners, usage bar, tables,
modal), with `.dark` variants and narrow-screen adaptation (the key/value list becomes a single column).
