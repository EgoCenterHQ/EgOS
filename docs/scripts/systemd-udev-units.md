# systemd units, drop-ins and udev rule

All generated by the EgOS4 scripts (identical on amd64 and arm64, except `egos-growroot`).

## Boot order

```
1st boot:  egos-sshkeys ─┐
           (arm64) egos-growroot ─→ first-boot-setup ─→ setup-webapp.sh ─→ reboot
           egos-pool ─→ docker, smbd ─→ egos-pool-guard

2nd boot:  egos-pool ─→ docker ─→ docker-compose-startup (after time-sync + DNS) ─→ deploy-compose.sh
                                └→ egos-pool-guard

always:    udev "egos-data*" added ─→ egos-reattach ─→ egos-storage _autoreattach
```

## Units

| Unit | Type | Ordering / conditions | Runs |
|---|---|---|---|
| `first-boot-setup.service` | oneshot, RemainAfterExit | `After/Wants=network.target`; only if `/var/lib/setup-complete` is **missing** | `/usr/local/bin/setup-webapp.sh` |
| `docker-compose-startup.service` | oneshot, RemainAfterExit | `After=network-online.target docker.service`, `Requires=docker.service`; only if `setup-complete` **exists** and `docker-compose-done` is **missing**. Drop-in `10-timesync.conf`: `After/Wants=time-sync.target`. `ExecStartPre` waits for DNS up to 120 s | `/usr/local/bin/deploy-compose.sh` |
| `egos-sshkeys.service` | oneshot | `DefaultDependencies=no`, `After=local-fs.target`, `Before=ssh.service ssh.socket sockets.target`; only if `/etc/ssh/ssh_host_ed25519_key` is missing | `ssh-keygen -A` |
| `egos-growroot.service` (arm64) | oneshot | `Before=first-boot-setup.service`; only if `/var/lib/egos-growroot-done` is missing | `/usr/local/bin/egos-growroot.sh` |
| `egos-pool.service` | simple | `After=local-fs.target`, `Before=docker.service smbd.service egos-pool-guard.service`; `TimeoutStartSec=150`, `Restart=on-failure` (5 s) | `ExecStart=egos-storage _pool`, `ExecStartPost=egos-storage _pool-ready`, `ExecStop=-umount /srv/egos/pool` |
| `egos-pool-guard.service` | oneshot | `After=docker.service egos-pool.service docker-compose-startup.service`, `Wants=egos-pool.service` | `egos-storage _guard` |
| `egos-reattach.service` | oneshot, not enabled (udev starts it) | `After=egos-pool.service docker.service egos-pool-guard.service`; `TimeoutStartSec=1200` | `egos-storage _autoreattach` |
| `egos-storage-job` | transient (`systemd-run`) | created by `egos-storage job …`, `--collect` | `egos-storage _job …` |

## Drop-ins

| File | Contents | Why |
|---|---|---|
| `/etc/systemd/system/docker.service.d/10-egos-pool.conf` | `Wants=` + `After=egos-pool.service` | containers restarted by the Docker daemon must find the pool mounted |
| `/etc/systemd/system/smbd.service.d/10-egos-pool.conf` | same | the `[media]` share is on the pool |
| `/etc/systemd/system/docker-compose-startup.service.d/10-timesync.conf` | `After/Wants=time-sync.target` | correct clock before the TLS pulls of the images |

## udev rule

`/etc/udev/rules.d/90-egos-reattach.rules`:

```
ACTION=="add", SUBSYSTEM=="block", ENV{DEVTYPE}=="partition", ENV{ID_FS_LABEL}=="egos-data*", \
  TAG+="systemd", ENV{SYSTEMD_WANTS}+="egos-reattach.service"
```

udev must not run long jobs (`RUN+=` is killed after a few seconds): that is why it starts a service.
At boot every present disk is "added": in that case `_autoreattach` does nothing.

## Network configuration

| File | Contents |
|---|---|
| `/etc/systemd/network/20-wired.network` | `Name=eth* en*`, `DHCP=yes` (Wi-Fi is not managed by networkd: `setup-webapp.sh` configures it as an AP) |
| `/etc/systemd/resolved.conf.d/egos.conf` | `MulticastDNS=no`, `LLMNR=no` (mDNS is done by avahi on 5353, LLMNR by wsdd2 on 5355: no conflicts) |
| `/etc/resolv.conf` | link to `/run/systemd/resolve/stub-resolv.conf` |
| `/etc/avahi/avahi-daemon.conf` | `host-name=setupbox` (commented out at the end of setup), IPv4+IPv6, publishes addresses |
