## Purpose

Minimal reader for the **albumartist**, **artist**, **album** tags.
Formats: MP3 (ID3v2.2/2.3/2.4 + ID3v1), FLAC, Ogg Vorbis, Opus, M4A/MP4. Any other format → empty tags.

```python
read_tags(path) -> {"albumartist": str|None, "artist": str|None, "album": str|None}
```

Command-line use (debugging): `python3 audiotags.py file1.mp3 file2.flac` prints the name and tags.

## Constants

| Name | Contents |
|---|---|
| `KEYS` | `("albumartist", "artist", "album")` |
| `ID3_MAP` | ID3 frames: `TPE2/TP2` → albumartist, `TPE1/TP1` → artist, `TALB/TAL` → album |
| `VORBIS_MAP` | `ALBUMARTIST`/`ALBUM ARTIST` → albumartist, `ARTIST`, `ALBUM` |
| `MP4_MAP`, `MP4_CONTAINERS` | atoms `aART`, `©ART`, `©alb`; containers `moov udta meta ilst` |

## Functions

| Function | Description |
|---|---|
| `_empty()` | dictionary with the three keys set to `None` |
| `_clean(s)` | NUL → `/`, strips spaces and `/` at the edges, empty string → `None` |
| `_syncsafe(b)` | decodes an ID3 "syncsafe" integer (7 bits per byte) |
| `_id3_text(data)` | decodes a text frame according to the encoding byte (0 Latin-1, 1 UTF-16, 2 UTF-16-BE, 3 UTF-8); for v2.4 multiple values (NUL-separated) keeps the first |
| `read_id3v2(f)` | reads the ID3v2 header at the start of the file, handles unsynchronisation (global in v2.2/2.3, per frame in v2.4) and the extended header, reads the mapped frames up to the padding; returns `(tags, tag_end)` |
| `read_id3v1(f)` | reads the final 128 `TAG` bytes (artist bytes 33–63, album 63–93) |
| `_vorbis_comments(b)` | parses a Vorbis comment block according to `VORBIS_MAP` (first value wins) |
| `read_flac(f, start)` | checks `fLaC`, walks the metadata blocks and reads the type-4 block (VORBIS_COMMENT) |
| `read_ogg(f, max_bytes=16 MiB)` | reassembles the 2nd logical packet from the `OggS` pages (it can span many pages if it holds the cover art) and reads it as a Vorbis (`\x03vorbis`) or Opus (`OpusTags`) comment |
| `read_mp4(f)` | walks the atoms with the inner function `walk(start, stop, depth)` (max depth 6, 64-bit atoms, `meta` with 4 version bytes) and reads the `data` child of the atoms in `MP4_MAP` |
| `read_tags(path)` | picks the reader from the extension: m4a/mp4/aac/alac/m4b → MP4; ogg/opus/oga → Ogg; otherwise ID3v2 (FLAC can also start with ID3) then FLAC, falling back to ID3v1 for the missing fields. I/O or format errors → empty tags |
