# dirtree.sh

| | |
|---|---|
| **Path** | `/usr/local/bin/dirtree.sh` |
| **Generated by** | section 10 of the EgOS4 scripts |
| **Started by** | `deploy-compose.sh`, 2nd boot |
| **Runs at the end** | `exec ./wizardall2.sh` |

## Purpose

Creates the stack folders, copies the files from staging, generates credentials and `.env`, configures Samba and hands
over to the wizard.

## Variables

| Variable | Value |
|---|---|
| `STAGE` | `/usr/local/share/stack` |
| `U` | user read from `/var/lib/setup-data.json` |
| `H` | `/home/$U` (must exist, otherwise exit 1) |
| `POOL` | `/srv/egos/pool` (must be mounted, otherwise exit 1: the folders would end up under an empty mount point) |

## Steps

1. **Folders on the pool**: `media/{Films,Musics,SerieTv,ROMs,downloads}` and `immich/upload`, owned by the user.
2. **Folders in the home** (system disk): `~/app/repos`, `~/app/jellyfin/{config,cache}`, `~/app/immich/postgres`.
3. **Copy** (not `mv`: if the service fails and runs again, the sources are still there) of `docker-compose.yml`,
   `wizardall2.sh`, `jellsrv.json`, `jellremot.json` into `~/app/repos`, and the `egos-home/` folder
   (`cp -rT`, so a retry copies over it instead of nesting it).
4. **Credentials** (Python block, `json.dump` handles the escaping):
   - `immichset.json` = `{"email", "password", "name": user}` → Immich administrator;
   - `jelluser.json` = `{"Name": user, "Password"}` → Jellyfin administrator.
   They are not included in the ISO: this way test credentials never end up in the image.
5. **`.env`**: `env.template` with `__HOME__` replaced by the absolute path (compose does not expand `$HOME` in `.env` files).
6. `chmod +x wizardall2.sh`, `chown -R` of `~/app`.
7. **Samba**: writes `/etc/samba/smb.conf` with the **`[media]`** share on `/srv/egos/pool/media`, setup user
   only, SMB2 minimum, no guests; `smbpasswd -a` with the same password; avahi service `_smb._tcp`
   (`EgoCenter`); restarts smbd and avahi, then wsdd2 (it has `BindsTo` on smbd, so it is restarted separately; `|| true`
   because network discovery is cosmetic).
8. `cd ~/app/repos && exec ./wizardall2.sh`.

Every step is idempotent: running them again at the next boot does no harm.
