# webapp.py

| | |
|---|---|
| **Path** | `/usr/local/bin/webapp.py` |
| **Generated by** | section 8 of the EgOS4 scripts |
| **Language** | Python 3, standard library only (`http.server`) |
| **Started by** | `setup-webapp.sh`, 1st boot |
| **Listens on** | `0.0.0.0:80` |

## Purpose

Shows the "System Setup" form (Email, Username, Password) and saves the submitted data to `/var/lib/setup-data.json`.

## Elements

### `HTML` (constant)
Dark responsive page with the `POST /` form and the hint "Connect to **SetupBox** WiFi or visit
**http://setupbox.local**".

### class `Handler(BaseHTTPRequestHandler)`

| Method | Behaviour |
|---|---|
| `log_message(format, *args)` | empty: no request logging |
| `do_GET()` | any path → 200 with `HTML` (needed for the captive portal: the Android/Apple/Windows probes get the page) |
| `do_POST()` | reads `Content-Length` bytes, `parse_qs`, builds `{"email","user","password"}` (empty string when missing), writes it to `/var/lib/setup-data.json`, answers "Setup Complete — The system will now reboot and deploy the stack." |

### Startup
`HTTPServer(('0.0.0.0', 80), Handler).serve_forever()`.

## Format of `setup-data.json`

```json
{"email": "you@example.com", "user": "username", "password": "…"}
```

## Limits

No validation of the username (`useradd` validates it), no password confirmation, no CSRF protection or
authentication: whoever submits the form first becomes the administrator.
