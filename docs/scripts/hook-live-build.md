# live-build hooks (amd64 only)

Generated by `EgOS4-amd64.sh` in `config/hooks/normal/`. live-build runs them during `lb build`.

## 0400-egos.hook.chroot

| | |
|---|---|
| **Section** | 4c |
| **When** | inside the chroot of the live system (= the installed system) |
| **Shell** | `/bin/sh`, `set -e`, `DEBIAN_FRONTEND=noninteractive` |

Steps:

1. purges `ifupdown dhcpcd-base isc-dhcp-client network-manager` if installed (only systemd-networkd may manage the network);
2. deletes `/etc/ssh/ssh_host_*` (each box generates its own at the 1st boot with `egos-sshkeys`);
3. adds to `/etc/skel/.bashrc` the loading of `/etc/profile.d/egos-storage.sh`: Cockpit's terminal starts a
   **non-login** bash, which does not read `/etc/profile.d`. The user created at setup copies `.bashrc` from `/etc/skel`.

> **Never** `apt-get install` in this hook: packages added by a hook are not in `chroot.packages.install`,
> so live-build puts them in `filesystem.packages-remove` and d-i uninstalls them at the end of the installation
> (section 13 checks for this).

## 0500-bootloader-default.hook.binary

| | |
|---|---|
| **Section** | 5 |
| **When** | "binary" stage (cwd = `binary/`, with a `cd binary` fallback) |

Makes the installer the default entry with a 5-second timeout, based on the **actual** files generated by live-build trixie.
Every assumption is checked: if it does not match, the build fails and prints the file.

| Firmware | Actions | Check |
|---|---|---|
| BIOS (isolinux) | removes `menu default` from `live.cfg`, adds it after `label installstart` in `install.cfg`, `timeout 50` (tenths of a second) in `isolinux.cfg` | `label installstart` exists, `timeout 50` present |
| UEFI (GRUB) | appends `set default="Start installer"` and `set timeout=5` to `grub.cfg` (the last `set` wins) | `menuentry 'Start installer'` present in `install_start.cfg` (grep independent of the quotes) |

Messages: `0500 BIOS ok: default=installstart, timeout 5s` and `0500 UEFI ok: …`; errors `ERROR 0500: …`.
