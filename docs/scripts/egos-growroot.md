# egos-growroot.sh (arm64 only)

| | |
|---|---|
| **Path** | `/usr/local/bin/egos-growroot.sh` |
| **Generated by** | section 11b of `EgOS4-arm64.sh` |
| **Started by** | `egos-growroot.service` (`Before=first-boot-setup.service`, condition: `/var/lib/egos-growroot-done` missing) |
| **When** | 1st boot, once |

## Purpose

The `.img` image is small (rootfs × 1.3 + 512 MB); at the first boot the root partition is grown to fill the whole NVMe.

## Steps

1. `SRC` = device of `/`; `PART` = its name; `DISK` = parent disk (`lsblk PKNAME`); `NUM` = partition number
   from `/sys/class/block/<part>/partition`.
2. `growpart $DISK $NUM` (exit code 1 = "NOCHANGE", not an error: `|| true`).
3. `resize2fs $SRC` (online).
4. Creates `/var/lib/egos-growroot-done` and disables the service.

## Functions

None.
