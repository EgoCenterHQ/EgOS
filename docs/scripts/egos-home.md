# egos-home — home page with one card per container

| | |
|---|---|
| **Path** | `/usr/local/share/stack/egos-home/` → copied to `~/app/repos/egos-home/` by [dirtree.sh](dirtree.md) |
| **Files** | `home.py` (server + page), `docker-proxy.cfg` (proxy rules), `icons/*.svg` |
| **Generated by** | section 11 of the EgOS4 scripts (heredocs `EGOSHOME_*_EOF`), since 4.3.0 |
| **Containers** | `egos-home` (`python:3.13-alpine`) and `egos-home-docker-proxy` (`tecnativa/docker-socket-proxy:0.3.0`), both in the main `egos` compose project, see [stack-configuration.md](stack-configuration.md) |
| **Address** | `http://egocenter.local:8000` (or the box's IP) |
| **Language** | Python 3, standard library only; page texts in Italian |

## Purpose

A launcher for the box: one card per service, with a link. It follows Docker by itself, so the
optional stacks (`egos-extras enable qbtt`) and anything the user adds appear without editing a list.

## How the cards are built

1. Every request reads `GET /containers/json?all=1` from the proxy (`DOCKER_API`, default
   `http://127.0.0.1:23750`).
2. **One card per container.** Port: label `egos.home.port`, otherwise the first published TCP port
   (bound to all addresses) that answers `HEAD /` as HTTP, then as HTTPS. The probe result is cached for
   10 minutes. Databases, BitTorrent, Redis… do not speak HTTP and never get a card.
3. **Name, description, icon, order**: `egos.home.*` labels, otherwise defaults for known images (`KNOWN`:
   Immich, Jellyfin, qBittorrent, torrent-web, BentoPDF, Multi-scrobbler), otherwise the container name and
   image. Without `icons/<id>.svg` the card shows the initial on a colour derived from the name.
4. **State** from Docker: `on`; `warn` (running but `(unhealthy)`: yellow border, "unhealthy"); `off` (grey,
   not clickable). A stopped container keeps its card if it has a `port` label or was seen running since
   egos-home started.
5. **Static cards** (`STATIC`): services that are not containers — Cockpit (9090, https), checked by
   connecting to the port.
6. Links are built from the request's `Host` header (validated) + port; `egos.home.url` replaces the link
   (e.g. a public domain) and the card shows `↗` instead of the port.
7. If the proxy does not answer, a banner says so and only the static cards remain.

The page refreshes the states every 15 s through `/api/status` and reloads itself when containers appear or
disappear.

## Labels

| Label | Effect |
|---|---|
| `egos.home.enable=false` | hides the container (set on `egos-home` and `docker-proxy`) |
| `egos.home.name`, `egos.home.desc` | card name and description |
| `egos.home.port`, `egos.home.scheme`, `egos.home.path` | port, `http`/`https`, path |
| `egos.home.url` | full link instead of host:port |
| `egos.home.icon` | `icons/<value>.svg` |
| `egos.home.order` | sort key (default 50; Immich 10, Jellyfin 20, Cockpit 90) |

Changing a label means recreating that container (`docker compose up -d` in its project).

## Endpoints

| Path | Answer |
|---|---|
| `/` | the page |
| `/api/status` | `{"docker": bool, "services": {id: "on"/"warn"/"off"}}` |
| `/icons/<id>.svg` | icon (`[a-z0-9-]+` only, cached 1 day) |
| `/health` | `ok` (container healthcheck) |

## Functions (`home.py`)

| Function | Description |
|---|---|
| `is_open(port)` | TCP connect to `127.0.0.1:port` (static cards) |
| `_speaks_http(port, tls)` | sends `HEAD /` (optionally over TLS without verification) and checks the answer starts with `HTTP/` |
| `web_scheme(port)` | `http`, `https` or `None`, cached `PROBE_TTL` (600 s) |
| `docker_containers()` | container list from the proxy, `None` if it does not answer |
| `known_for(image)` | defaults for a known image |
| `card_from_container(c)` | applies labels, port choice, defaults and state; `None` = no card |
| `services()` | containers (8 threads) + static cards, sorted by `order`, name |
| `request_host(header)` | host for the links, `FALLBACK_HOST` if the header is invalid |
| `icon_html(card)` | `<img>` of the icon or the generated initial |
| `render(host)` / `api_status()` | page / JSON |
| `Handler.do_GET` | routing; `send()` adds `no-store` and `nosniff` |

## Security

- The Docker socket goes **only** into the proxy. `docker-proxy.cfg` replaces the image's haproxy template and
  allows only `GET /containers/json` and `GET /_ping`; everything else answers 403. With the image's own
  `CONTAINERS=1` mode, `/containers/<id>/json` would expose every container's **environment variables**
  (passwords) and `/containers/<id>/logs` its logs to anything that can reach the proxy port.
- The proxy listens on `127.0.0.1:23750` (reachable by host processes and host-network containers), runs with
  `cap_drop: ALL` and `no-new-privileges`; it is not read-only because the image writes its `haproxy.cfg`
  at start.
- `egos-home`: read-only container, user 1000, host network (needed for the port probes); it has no
  authentication — it shows only links, on the LAN.

## Risks and limits

- The stack now pulls two more images (`python:3.13-alpine`, `tecnativa/docker-socket-proxy`, both pinned by
  digest). As for the other images, a failed pull makes `docker compose up` fail and the deployment retries at
  the next boot.
- Port 8000 must be free on the box.
- Boxes installed before 4.3 do not get egos-home by themselves (no `egos-update` yet): the files and the two
  services have to be added to `~/app/repos` by hand.
