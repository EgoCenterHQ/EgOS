# setup-webapp.sh

| | |
|---|---|
| **Path** | `/usr/local/bin/setup-webapp.sh` |
| **Generated by** | section 7 of `EgOS4-amd64.sh` / `EgOS4-arm64.sh` (quoted heredoc: `$` is not expanded at build time) + the 11b patch |
| **Started by** | `first-boot-setup.service`, only if `/var/lib/setup-complete` is missing |
| **When** | 1st boot, once |

## Purpose

Prepares the initial setup environment, waits for the user to fill in the web form, creates the Linux user, cleans
everything up and reboots.

## Steps

| # | Block | Detail |
|---|---|---|
| 1 | Interface detection | `WIFI` = first `wl*`/`wlan*` interface, `ETH` = first `en*`/`eth*` in `/sys/class/net` |
| 2 | **Wi-Fi access point** (only if there is a Wi-Fi card) | `rfkill unblock wlan` (11b patch), IP `192.168.50.1/24`; writes `/etc/hostapd/hostapd.conf`: SSID **`SetupBox`**, channel 7, 802.11g, WPA2-PSK, passphrase `setup1234`, `country_code=IT`, `ieee80211d=1` (11b patch); starts hostapd |
| 3 | Portal DHCP/DNS | `/etc/dnsmasq.d/setup.conf`: DHCP `192.168.50.10–50`, gateway and DNS = the box, `address=/#/192.168.50.1` (**every name** resolves to the box → phones and PCs open the "Sign in to network" popup by themselves), `setupbox.local`; starts dnsmasq |
| 4 | Redirection | iptables `PREROUTING`: incoming TCP 80 and 443 from Wi-Fi → `192.168.50.1:80` |
| 5 | Ethernet | `ip link set $ETH up` |
| 6 | mDNS | `/etc/avahi/services/http.service` (`_http._tcp` port 80, name `SetupBox`), restarts avahi: reachable as `http://setupbox.local` |
| 7 | Webapp | starts `/usr/local/bin/webapp.py` in the background |
| 8 | Wait | loops every 2 s until `/var/lib/setup-data.json` appears, then stops the webapp |
| 9 | User | reads `user`, `password`, `email`; `useradd -m -s /bin/bash`, `chpasswd`, groups `sudo` (or `wheel`) and `docker`; writes the email to `~/.email` |
| 10 | Cleanup | stops hostapd/dnsmasq, deletes their configuration and `http.service`; comments out `host-name=` in `avahi-daemon.conf` (from the 2nd boot the mDNS name becomes `egocenter.local`) and restarts avahi |
| 11 | End | creates `/var/lib/setup-complete`, disables `first-boot-setup.service`, `systemctl reboot` |

## Functions

None: a sequential script.

## Files touched

| File | Action |
|---|---|
| `/etc/hostapd/hostapd.conf`, `/etc/dnsmasq.d/setup.conf`, `/etc/avahi/services/http.service` | created and then deleted |
| `/etc/avahi/avahi-daemon.conf` | `host-name=` commented out |
| `/var/lib/setup-data.json` | created by the webapp, **kept** (used by dirtree, egos-storage, egos-extras) |
| `/var/lib/setup-complete` | end-of-setup flag |
| `/home/<user>/.email` | the email entered |

## Security notes

The form is plain HTTP, unauthenticated, on every interface; the AP passphrase is public and
`setup-data.json` holds the password in plain text.
