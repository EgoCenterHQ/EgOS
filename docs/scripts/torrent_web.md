## Purpose

A small web page for the LAN: you paste one or more searches (one per line), the page runs them through qBittorrent's
search engine, shows the results with filters (type, seeders, size, text) and adds them to the
downloads with one click.

## Configuration (environment variables)

| Variable | Default | Meaning |
|---|---|---|
| `QBIT_URL` | `http://localhost:8082` | address of the qBittorrent Web UI |
| `QBIT_USER`, `QBIT_PASS` | empty | Web UI credentials |
| `WEB_HOST` | `0.0.0.0` | listen address |
| `WEB_PORT` | `8083` | page port |
| `WEB_PASSWORD` | empty | if set, the page asks for user/password (Basic, any user) |
| `SEARCH_TIMEOUT` | 60 s | (constant) maximum duration of a search |

## Classes and functions

### `QbitError(Exception)`
Error with a message readable by the user.

### `QBittorrent` — minimal Web API client

| Method | Description |
|---|---|
| `__init__(url, user, password)` | stores the parameters, creates a lock and a session |
| `_new_session()` | urllib opener with a cookie jar and `Referer`/`Origin` headers (required by qBittorrent) |
| `_request(path, data, params, timeout)` | call to `/api/v2/<path>`; returns `(status, text)`; turns network errors into `QbitError` ("not reachable…") |
| `login()` | thread-safe; `auth/login`; accepts the `Ok.` body or checks with `app/version` (qBittorrent 5.2+ or localhost bypass); 403 = banned after too many attempts |
| `api(path, …)` | `login()` + request; on 403 logs in again once; ≥ 400 → `QbitError` |
| `enabled_plugins()` | names of the enabled search plugins |
| `search(text, category)` | `search/start` → waits for `Stopped` (max 60 s) → `search/results`; always `search/stop` and `search/delete`; normalises the results (`title, seeders, leechers, mb, site, page, link`) sorted by seeders |
| `add(link)` | `torrents/add` with the URL or the magnet |

`QB` = global instance.

### `PAGE` (constant)
HTML/CSS/JS page. Internal JS functions: `api(path, body)` (JSON fetch), `status(msg, error)`, `safeLink(u)` (accepts
only `http(s)://`), `download(btn, link)`, `showGroup(query, results)` (renders a group of results).

### `Handler(BaseHTTPRequestHandler)`

| Method | Description |
|---|---|
| `log_message` | logs to stdout with the client address |
| `_authorized()` | if `WEB_PASSWORD` is set, checks the Basic header with `hmac.compare_digest`; otherwise 401 + `WWW-Authenticate` |
| `_send(code, body, ctype)` | JSON or text response, `Cache-Control: no-store` |
| `_json_body()` | accepts only `application/json` (blocks forms from other sites: CSRF) and at most 100,000 bytes |
| `do_GET()` | `/` or `/index.html` → page; `/api/plugins` → enabled plugins (502 if qBittorrent does not answer); anything else → 404 |
| `do_POST()` | `/api/search` `{query, type}` → results; `/api/add` `{link}` (must start with `magnet:`, `http://`, `https://`) → adds it; errors 400/404/502 |

### `main()`
Starts `ThreadingHTTPServer`, warns if `WEB_PASSWORD` is missing, shuts down cleanly on Ctrl+C.
