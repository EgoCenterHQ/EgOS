# deploy-compose.sh

| | |
|---|---|
| **Path** | `/usr/local/bin/deploy-compose.sh` |
| **Generated by** | section 9 of the EgOS4 scripts |
| **Started by** | `docker-compose-startup.service` |
| **When** | 2nd boot (after `/var/lib/setup-complete`, as long as `/var/lib/docker-compose-done` is missing) |

## Purpose

Entry point of the stack deployment.

## Steps

1. `set -e`; if `/var/lib/setup-data.json` is missing → "No setup data", exit 1.
2. Runs `/usr/local/bin/dirtree.sh`, which in turn `exec`s `wizardall2.sh`.
3. Only if everything succeeded: creates `/var/lib/docker-compose-done` and disables the service.

If the wizard fails, `set -e` stops the script **before** the flag: the service retries at the next boot.

## Unit that starts it

`docker-compose-startup.service`:

- `After=network-online.target docker.service`, `Requires=docker.service`;
- drop-in `10-timesync.conf`: `After/Wants=time-sync.target` (correct clock before the TLS pulls);
- `ExecStartPre=-timeout 120 … until getent hosts deb.debian.org` (waits for DNS up to 120 s, the `-` ignores the timeout);
- `Type=oneshot`, `RemainAfterExit=yes`.

## Functions

None.
