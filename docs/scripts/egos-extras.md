# egos-extras

| | |
|---|---|
| **Path** | `/usr/local/bin/egos-extras` |
| **Generated by** | section 11a of the EgOS4 scripts |
| **Language** | Bash (`set -euo pipefail`) |
| **Stack sources** | `/usr/local/share/stack/extras/<name>` |

## Purpose

Enables or disables the **optional stacks**, present in the image but **not started**:

| Name | Contents | Target folder | Ports |
|---|---|---|---|
| `qbtt` | qBittorrent-nox + *torrent-web* search page + automatic sorting | `~/app/qbtt/qbittorrent-nox-easywebapp` | 8082 (Web UI), 8083 (search), 6881 tcp/udp |
| `bento` | BentoPDF (PDF tools in the browser) | `~/app/pdf/bento` | 8080 |

## Usage

```
egos-extras list               available stacks and status
egos-extras enable <name>      copies into ~/app, creates .env, starts
egos-extras disable <name>     stops (files and data stay)
```

## Initialisation

`U` = user from `/var/lib/setup-data.json` (must exist, otherwise "Setup user cannot be determined"),
`H` = their home from `getent passwd`.

## Functions

| Function | Description |
|---|---|
| `dest_of <name>` | target folder of the stack; returns 1 for unknown names |
| `compose_of <name>` | compose file: `bento.yml` for bento, `docker-compose.yml` for the others |
| `media_dir` | value of `JELLYFIN_MEDIA_LOCATION` in the main stack's `.env`, or `/srv/egos/pool/media` |
| `as_user <paths…>` | when run as root, `chown -R` to the setup user |
| `dc <dir> <arguments…>` | `docker compose -f <compose_of $NAME> …` inside `<dir>` |
| `do_list` | for `qbtt` and `bento` prints name, status (`not installed` / `running` / `stopped`) and folder |
| `do_enable` | creates the folder, copies the files with `cp -r --update=none` (it **never overwrites** existing files); if there is an `env.example` and no `.env` it generates one replacing `__MEDIA__`, `__UID__`, `__GID__` (mode 600); for qbtt it creates `qbittorrent/config` and the folders `downloads, Films, Musics, SerieTv`; if `.env` still contains `CHANGEME` it stops and asks you to edit it; otherwise `up -d --build`; for qbtt it reminds you to follow the README |
| `do_disable` | `docker compose down` (if installed) |

Dispatcher: `list` (default), `enable <name>`, `disable <name>`; otherwise it prints the usage and exits with 1.
